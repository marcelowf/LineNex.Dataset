### 🚀 **Sobre o Projeto**  

O LineNex Dataset é o módulo responsável pelo tratamento e preparação dos dados coletados das operações industriais. Ele realiza o processamento via pipelines de dados, incluindo limpeza, transformação e enriquecimento, além de aplicar técnicas de aprendizado de máquina para gerar insights, previsões e análises preditivas.

---

#### 🔧 Pré-requisitos

- Google Colab

Siga estes passos para configurar seu ambiente de desenvolvimento:

2. **Definir Ambiente:**
    Abra os arquivos localizados em Jupyter_Notebooks/ em seu Google Colab.
